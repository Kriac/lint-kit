# 介绍

## Lint Kit 是什么？

`@kriac/lint-kit` 是一款可组合的个人代码质量工具集。

## 包含什么

| 工具        | 用途                                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| ESLint      | 检查 JavaScript、TypeScript、Vue 与 TSX 代码；配置包含推荐规则、样式规则及导入排序，并兼容 Prettier。 |
| Stylelint   | 检查 CSS、SCSS、Vue 与 HTML 中的样式，并按规则整理属性顺序。                                          |
| Prettier    | 检查或修复支持文件的格式。                                                                            |
| Commitlint  | 校验提交信息；默认要求提交类型非空且属于允许的类型列表。                                              |
| lint-staged | 检查 Git 暂存文件；默认对匹配文件调用 `lint-kit check --fix`                                          |

## 风格说明

Lint Kit 优先采用 ESLint、Stylelint、Prettier 等工具提供的标准配置与推荐规则，不另起一套规则体系，在此基础上，我们补充了导入排序、样式属性排序和格式归一化等约定，帮助团队成员保持一致的代码风格，让不同人编写的代码读起来也更像出自同一人之手。

例如，条件分支即使只有一行，也统一使用花括号：

整理前：

```ts
if (isReady) start();
```

整理后：

```ts
if (isReady) {
  start();
}
```

运行 `pnpm lint-kit check --fix`，可自动修复支持的代码风格问题。

或许你会认为这很没必要，但在AI时代，收益会更加明显。
